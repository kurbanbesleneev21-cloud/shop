# TECHMARKET — маркетплейс электроники

Полноценный маркетплейс на **Next.js 15 (App Router) + React 19 + TypeScript + Tailwind CSS + Motion + PostgreSQL + Prisma**.

## Возможности
- **Покупатель:** регистрация (модальное окно при первом визите), вход, подтверждение email, SMS-подтверждение телефона (SMS.ru), восстановление пароля, каталог с фильтрами (цена, производитель, модель, цвет, память, диагональ, процессор, рейтинг, наличие, скидка) и сортировкой, поиск с подсказками, карточка товара (галерея с зумом и полноэкранным просмотром, характеристики по шаблону категории, отзывы только после подтверждённой покупки), избранное, корзина, промокоды, оформление заказа, личный кабинет (заказы, отмена, возврат, поддержка).
- **Продавец** (`/seller`): заявка, свои товары (редактор с загрузкой фото), заказы, статистика, финансы и запрос выплат.
- **Администратор** (`/admin`): дашборд с графиками, товары (создание, копирование, публикация, быстрые цены/остатки), менеджер изображений (drag&drop, порядок, главное фото, замена, превью, прогресс), категории с шаблонами характеристик, бренды, продавцы (модерация, комиссии, выплаты), покупатели, заказы (статусы, история, возвраты), финансы (CSV/Excel), отзывы (модерация, ответы, жалобы), промокоды и акции, внешний вид (черновики → предпросмотр → публикация), страницы, Telegram-уведомления, AI-генератор карточек, глобальные настройки (28 разделов), журнал изменений, резервное копирование.

## Безопасность
bcrypt-хеши паролей, JWT-сессии в httpOnly-cookie с отзывом (tokenVersion), проверка ролей на сервере (middleware + каждый API), zod-валидация, Prisma (параметризованные запросы), проверка Origin для мутаций, rate limiting (PostgreSQL), валидация изображений через декодирование sharp, секреты (токены Telegram/AI/SMTP/SMS) шифруются AES-256-GCM и никогда не попадают во frontend, журнал критических действий.

## Запуск
```bash
cp .env.example .env   # заполните DATABASE_URL, DIRECT_URL, AUTH_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm install
npx prisma db push
npm run db:seed        # демо-данные (только если база пустая)
npm run dev
```
На Vercel команда `npm run build` сама применяет схему и создаёт администратора. Изображения хранятся в Vercel Blob (`BLOB_READ_WRITE_TOKEN`), без него — в PostgreSQL.

Демо-аккаунты (из сида): покупатель `buyer@techmarket.ru / buyer12345`, продавец `seller@techmarket.ru / seller12345`. Администратор — из переменных `ADMIN_EMAIL` / `ADMIN_PASSWORD`.
